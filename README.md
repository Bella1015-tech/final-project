## 專題簡介

每個人的身形都不同，但市面上的穿搭建議往往是通用的。我們設計一個系統，用**數學模型**自動分類使用者體型，給出**客製化穿搭建議**。

### 核心功能
- 衣櫥管理：新增、查看、刪除衣服
- **體型分析**：輸入三圍（胸、腰、臀）自動分類
  - 沙漏型、梨型、蘋果型、倒三角型、矩形型
- 穿搭推薦：隨機組合衣服推薦
